# Web 本地草稿

当前只实现未登录开发预览草稿。数据库 `snaptium-preview-drafts`（版本 1）与未来按服务实例、用户、笔记、基础修订隔离的正式草稿分开，不能将预览内容自动绑定到账号。没有离线笔记库、服务端保存、同步队列、偏好设置或上传恢复能力。

## 保存与恢复

- 原始 Markdown、编辑模式、保存时间、独立 UUID 与行版本经运行时校验后写入 IndexedDB。源码可保留尚未支持的语法，不经过富文本投影；恢复时 textarea 显示遵循浏览器的 LF 换行规则，存储副本保留原文。
- 富文本应用成功后同步发送快照，源码输入即时发送快照；仅切换编辑模式也会保存。没有编辑操作时不会保存示例内容。
- 每页使用新的草稿 ID，恢复也创建新副本，保留原记录。多个标签页不更新彼此草稿，无最后写入者覆盖问题。恢复菜单最多列出最近 20 份，不自动删除更早记录。
- 写入串行执行，等待中的快照合并为最新状态；只有事务完成才显示“已保存到当前浏览器”。请求严格 durability，具体持久性仍受浏览器与操作系统约束，参见 [IndexedDB 使用说明](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)。
- 当前预览草稿上限为 1 MiB UTF-8，与富文本解析 512 KiB 上限独立。超限、事务中断、空间不足、禁用 IndexedDB、版本不兼容都会显示失败，保持页面内容和此前已提交记录。保存失败可重试最新快照，不记录内容或底层错误详情。
- 未来数据库版本拒绝打开，不降级、不删除数据库；已读到的异常行拒绝恢复，不清除原记录。其他页面升级数据库时关闭连接，后续操作尝试安全重连。

## 数据安全边界

草稿未加密，受同源访问控制而不是账号授权保护。同一浏览器配置的其他使用者可访问开发预览草稿，不应写入真实敏感信息。浏览器清理、配额回收、隐私模式结束、未完成写入时崩溃都可能导致丢失；不能作为唯一备份。

写入中或失败时尝试通过 `beforeunload` 提醒用户。浏览器可能不显示提醒，尤其是移动端或没有用户交互时；不依赖卸载回调完成异步保存。正常组件卸载等待队列结束再关闭连接。

正式账号草稿、服务端基础修订、会话失效、冲突解决、偏好与附件恢复仍属于后续任务，7.5 不标记整体完成。

## 验证

```text
pnpm test:drafts
pnpm check
```

CI 的 `pnpm check` 包含草稿测试。fake-indexeddb 验证关闭重开、原文保留、独立恢复副本、边界限制、事务中断、未来版本和异常行拒绝；写入器测试验证串行合并与失败重试；Vue/真实编辑器组件测试验证恢复选择、源码输入、存储禁用与离页提醒。这些不是浏览器 E2E、真实配额或断电持久性测试；仍需在可用浏览器中手工验证刷新恢复、多标签页、隐私模式与中文 IME。
